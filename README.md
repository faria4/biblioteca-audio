# Biblioteca em Áudio

Podcasts em português sobre os livros da biblioteca, gerados no NotebookLM.

**Site:** https://faria4.github.io/biblioteca-audio/

## Como adicionar um áudio novo

1. Renomeie o arquivo com o **número do livro** (o número aparece no site) e a **parte**:
   - `01-1.m4a` → livro 1, parte 1
   - `01-2.m4a` → livro 1, parte 2
   - `27-1.m4a` → livro 27, parte 1
2. Abra a Release **Áudios** em https://github.com/faria4/biblioteca-audio/releases/tag/audios
3. Clique no lápis (**Edit**), arraste os arquivos para a área "Attach binaries" e clique em **Update release**.
4. Pronto: o site mostra o áudio sozinho na próxima vez que for aberto.

Aceita `.m4a` e `.mp3`. Cada arquivo pode ter até 2 GB.

O progresso de quem ouve (onde parou, partes já ouvidas, velocidade) fica salvo no próprio celular ou computador de cada pessoa.
